伴航 NavPal · 隐私政策

最后更新：2026-10-06

我们的承诺

伴航 NavPal（以下简称"本扩展"）将用户隐私视为核心价值。我们不收集、不存储、不上传任何个人信息到任何远程服务器。

信息收集

本扩展不收集任何个人信息。所有数据（包括书签、分组、主题偏好、语言设置等）均使用浏览器的 storage API 存储在您的本地设备上。

本扩展没有：

  • 没有远程服务器
  • 没有用户账号系统
  • 没有数据上传
  • 没有第三方分析或跟踪服务
  • 没有广告 SDK

数据存储与使用

以下数据仅存储在您的本地浏览器中，由您完全控制：

  • 书签数据：网站名称、URL、分组归属、排序、显示/隐藏状态
  • 分组数据：分组名称、图标、颜色、排序
  • 偏好设置：界面语言、主题、布局偏好
  • 无痕模式密码：经编码后保存在本地，用于解锁隐藏内容

上述数据的所有读写操作均通过 Chrome/Edge 扩展的 chrome.storage.local API 在本地完成，绝不会传输到任何外部服务器。

权限说明

权限 用途 数据去向
storage 存储书签、分组和用户偏好设置 仅本地浏览器

第三方服务

本扩展不使用任何第三方分析工具、广告平台或数据收集服务。

数据删除

您可以通过以下方式完全控制您的数据：

  • 清除数据：在扩展设置中使用"清除所有数据"功能
  • 卸载扩展：卸载后，浏览器会自动删除扩展关联的所有本地存储数据
  • 导出数据：使用 JSON 导出功能备份数据到本地文件

开源与可审计

本扩展为开源项目（MIT 许可），源代码托管在 GitHub，可供任何人审计：

https://github.com/panris/navpal-extension

儿童隐私

本扩展不针对 13 岁以下儿童，也不会故意收集儿童的个人信息。

政策更新

如本隐私政策有重大更新，我们将在扩展更新日志中说明，并更新本页面的"最后更新"日期。
